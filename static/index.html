Runner Log: Gestor de Carreras

Esta aplicación web permite administrar y registrar entrenamientos de running de manera sencilla. Se pueden registrar zapatillas y sesiones de carrera, así como vincular entrenamientos específicos con el calzado utilizado. Los registros pueden ser agregados, modificados, consultados o eliminados, permitiendo llevar un control completo del historial de entrenamientos y el desgaste del equipamiento.
